How this works

  1. Add a server you own. The list is saved in this browser only, never the RCON password.
  2. Pick a tool on the right: status, details, console or test player.
  3. Tick the box that says you own the server or have permission, then press the green button.

Server details need enable-query=true. The console needs enable-rcon=true and the RCON password. The test player needs online-mode=false.

This page only works on your own computer. Never test servers you do not own.
